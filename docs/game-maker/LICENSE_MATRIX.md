# Game Maker licence matrix

What may be shipped, what may be sold, and what blocks a publish.

## Code dependencies

| Package | Licence | Commercial use | Attribution required | Copyleft risk |
| --- | --- | --- | --- | --- |
| `playcanvas` 2.21.4 | MIT | Yes | Yes — retain the copyright notice | None |
| `phaser` 4.2.1 | MIT | Yes | Yes — retain the copyright notice | None |
| `zod` 4.4.3 | MIT | Yes | Yes | None |
| `nanoid` 6.0.1 | MIT | Yes | Yes | None |
| `comlink` 4.4.2 | Apache-2.0 | Yes | Yes — retain NOTICE and state changes | None (patent grant included) |

All are permissive. Attribution is satisfied by the existing
`THIRDPARTY_NOTICES.md` at the repository root.

## Generated content

Everything Game Maker produces today is **procedural**: meshes come from
`MeshSpec` parameters, materials from `MaterialDefinition` parameters, worlds
from a seed. Nothing is derived from a third-party asset library and nothing
is derived from model weights, so generated games carry no third-party asset
licence.

Every asset records this in `AssetRecord.provenance`:

```ts
provenance: {
  origin: "procedural",
  license: "Generated by Clyra Game Maker — no third-party rights",
  generator: "material/v1",
  seed: 77221,
  generatedAt: 1755000000000,
  commercialUseAllowed: true,
}
```

`commercialUseAllowed: false` is a hard publish blocker: `licenseIssues()` in
`src/features/game-maker/ir/project.ts` turns it into a publish-time error
naming the offending asset (spec §254). Nothing in the product sets it false
yet — it exists so that the first imported or GPU-generated asset cannot slip
into a published build unchecked.

## Model weights

The AI orchestrator calls a hosted model API (DeepSeek, via the application's
existing server-side proxy). No model weights are distributed with this
product, so no model-weight licence applies to it.

**If GPU asset generation is ever added**, its model licence must be recorded
here *before* integration, separately from its code licence, covering at
minimum: territorial restrictions, commercial restrictions, redistribution
rules, hosted-service rules, user-count limits and attribution (spec §12,
§32). A code licence of MIT says nothing about the weights.

## Fonts, audio, textures

None are bundled. Audio cues are parameter-driven and synthesised at runtime;
there are no texture files, because materials are evaluated procedurally.
