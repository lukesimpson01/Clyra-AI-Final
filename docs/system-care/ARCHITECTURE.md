# Architecture

Current foundation flow:

```text
SystemCareWorkspace (untrusted renderer)
  → typed preload methods
  → allowlisted IPC handlers
  → SystemCareService (Electron main)
  → fixed read-only OS observations
  → normalized DeviceProfile + ActivitySnapshot
  → deterministic health factors
```

There is no command IPC. `system-care-service.mjs` accepts no executable, arguments, command text or path from the renderer. Smart Scan is read-only, cancellable, and publishes actual job completion events. Live activity uses fixed macOS/Windows observation calls and groups app helpers before sending bounded aggregate rows to the renderer. Network throughput is calculated from two local interface-counter snapshots.

The internet speed test is a separate user-invoked read-only IPC method. It contacts a fixed Cloudflare endpoint, transfers generated bytes only, and cannot accept a URL, host, payload, executable, path, or command from the renderer.

Future heavy storage work belongs in a Rust N-API module loaded by Electron main. The AI will see aggregates and a typed tool registry; actions pass through policy, preview, approval, execution and verification. A scoped privileged helper is a later safety phase and must never accept arbitrary strings as commands.

The current launcher/workspace registration reuses Clyra's catalogue, task view, semantic tokens, UI primitives and motion system. The renderer is split into a workspace controller, page module, domain model and reusable System Care primitives; unavailable native providers are represented explicitly rather than mocked.
