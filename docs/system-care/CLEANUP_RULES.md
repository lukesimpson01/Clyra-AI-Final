# Cleanup rules

No cleanup rule executes in Phase 1. Future rules are versioned data and must declare platform, verified application identity, category, risk, consequence, allowed target roots, app-running constraint and version bounds.

Protected by default: Documents, Desktop, Pictures, Videos, Music, source code, SSH keys, password databases, browser profiles/passwords, authentication tokens, wallets, cloud credentials, system executables, Windows System32 and macOS System.

Path substring matching alone is forbidden. Personal data is review-only. Registry cleaning, RAM cleaning, SSD defragmentation and vague optimizer operations are forbidden product categories.
